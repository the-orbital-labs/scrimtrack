# ScrimTrack Support

ScrimTrack is a community-maintained, unofficial Chrome extension. Support is
provided on a best-effort basis through this repository.

## Before Requesting Help

- Update to the latest ScrimTrack version from the Chrome Web Store.
- Review the [README](README.md) and search
  [existing issues](https://github.com/the-orbital-labs/scrimtrack/issues) for
  the same question or problem.
- Do not include learning history, credentials, or other private information in
  public posts, screenshots, or logs.

## Bugs

Report reproducible ScrimTrack problems with the
[bug report form](https://github.com/the-orbital-labs/scrimtrack/issues/new?template=bug_report.yml).
Include the extension version, browser and operating system, steps to reproduce,
and the expected and actual behavior.

## Feature Requests

Suggest focused improvements with the
[feature request form](https://github.com/the-orbital-labs/scrimtrack/issues/new?template=feature_request.yml).
Requests should remain within the project's local-first scope and keep browser
permissions minimal.

## Usage Questions

For a question that is not a bug or feature request, search the
[issue tracker](https://github.com/the-orbital-labs/scrimtrack/issues) and open
a new issue if it has not already been answered. Describe what you are trying
to do, what you have tried, and your ScrimTrack and browser versions.

ScrimTrack is not affiliated with Scrimba. Questions about Scrimba accounts,
billing, course access, or course content should be directed to Scrimba's own
support channels.

## Privacy and Local Data

Read the [Privacy Policy](PRIVACY.md) for details about local storage, data
export, retention, and reset behavior. For a sensitive privacy question that
cannot be discussed publicly, email `hello@scrimtrack.xyz`.

## Security Vulnerabilities

Do not report suspected vulnerabilities in a public issue. Follow the private
reporting instructions in the [Security Policy](SECURITY.md).

## Response Expectations

There is no guaranteed response or resolution time for general support
requests. Clear, reproducible reports are easier to investigate, and community
members are welcome to help answer public questions.
